# Telegram Anonim Support & Multi-Department Bot

Корпоративный Telegram-бот для анонимной связи магазинов со службами компании (IT, Бухгалтерия, Склад, Офис) и проведения массовых рассылок от руководства.

> 📄 **Полная инструкция на русском языке:** подробное руководство со всеми сценариями, скриншотами логики и командами находится в файле [**ИНСТРУКЦИЯ.md**](file:///c:/Users/1/Desktop/Проекты/TelegramAnonim/ИНСТРУКЦИЯ.md).

## Краткий старт:
```powershell
# 1. Запуск виртуального окружения
.\.venv\Scripts\Activate.ps1

# 2. Запуск бота
python bot.py
```

## Главные возможности:
- **Полная изоляция магазинов:** магазины не состоят в одной группе и не видят сообщения друг друга.
- **Анонимность поддержки:** магазин видит только ответы бота, профили сотрудников скрыты.
- **Мульти-отделы:** распределение тикетов по отдельным группам (`IT`, `Бухгалтерия`, `Склад`, `Офис`).
- **Интерактивные статусы:** кнопки `[ 🟡 Взяти в роботу ]` и `[ 🟢 Закрити питання ]` в группах отделов.
- **Живые реакции Telegram:** `👀` при получении, `🔥` при срочности, `👍` при закрытии.
- **Оценка качества:** интерактивный рейтинг `⭐ 1-5` после решения вопроса.
- **Массовые рассылки от руководства:** персональная доставка сообщений («Обновить 1С») во все магазины с изоляцией ответов.
- **Динамическое подключение групп:** команда `/set_group` прямо в Telegram без правок кода.
